# Structify | DSA Visualizer

Structify is a powerful, interactive Data Structures and Algorithms (DSA) visualizer built to make learning computer science concepts intuitive and engaging. Instead of just reading code, users can see algorithms in action—step by step.

## 🚀 Features

- **Interactive Visualizations**: Real-time rendering of Stacks, Queues, Linked Lists, Trees, and Heaps.
- **AI Integration**: Each visualizer is paired with a specialized AI assistant to explain concepts and answer questions.
- **Premium UI/UX**: Built with React, Tailwind CSS, and GSAP for a smooth, glassmorphic, and professional experience.
- **DSA Optimized**: Perfect for students, interview preparation, and visual learners.

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite
- **Styling**: Tailwind CSS (v4), GSAP for animations
- **Routing**: React Router DOM
- **Logic**: Custom DSA implementations in JavaScript

## 📦 Getting Started

1. **Clone the repository**:
   ```bash
   git clone [your-repo-link]
   ```
2. **Install dependencies**:
   ```bash
   npm install
   ```
3. **Set up Environment Variables**:
   Create a `.env` file in the root directory and add your Gemini API Key:
   ```env
   VITE_GEMINI_API_KEY=your_api_key_here
   ```
4. **Run the development server**:
   ```bash
   npm run dev
   ```
